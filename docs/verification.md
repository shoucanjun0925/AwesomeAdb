# 0.3.0 验证说明

运行类型检查、自动化测试、Sites 生产构建和 Windows 助手自检。测试覆盖设备备注、关联与用户隔离、连接历史、文件传输、取消、失败重试、预览、来源及会话保护，以及受管 ADB 的首次提取、保留已安装版本、更新校验和失败清理。

助手 `--self-test` 验证全部内嵌 ADB 文件，使用隔离配置目录和仅含 Windows 系统目录的 PATH，不启动或停止真实设备服务。公开源码和通用包另外检查私人网址、项目身份、本机路径及凭证。

自动化文件传输使用设备服务替身和真实 Windows 文件系统，不能替代全部硬件验证。仍需在对应环境检查 USB 首次授权、多设备、真实无线配对、大文件、权限拒绝和断线，以及干净 Windows 10/11、Edge/Chrome 权限恢复与 125%/150% 显示缩放。

部署成功和助手自检通过不等同于这些硬件场景已全部验收。交付报告应说明当次实际执行范围。
